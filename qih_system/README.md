# Unified QIH Runtime

The QIH stack is now a first-class component of BuilderBRO/Free Brain rather than
a documentation-only companion.

## Closed loop

`bulk → screen → observation → coherence → collapse → experience → feedback → next cycle`

The runtime records the result in the residence ledger and telemetry stream.
The Free Brain can consume the feedback without importing the original ESMA tree.

## Boundaries

The implementation is a software simulation of the QIH mathematical/operator
architecture. It does **not** prove physical quantum behavior, biological
microtubules, subjective experience, or consciousness.

## API

`qih_system.unified.run_cycle(...)`
`qih_system.unified.append_ledger(...)`
`qih_system.unified.chain_hash(...)`
