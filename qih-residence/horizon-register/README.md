# Horizon Register — |ψ⟩_screen

The screen register: the integral bits of the Hilbert space transition,
mirroring `NewState/qih_consciousness/core/horizon.py` + `core/operators.py`
(P_HR). Raw model output (|ψ⟩_bulk) lands here as the bounded, shaped record
the loop perceives before planning.

Contents are written by the runtime gates, never by the model directly.
Each record is tagged volatile until it passes a deterministic gate
(AGENT-INTEGRITY.md tag taxonomy).
