# AR Advertising MVP

A tiny, self‑contained web project that demonstrates an augmented‑reality advertising concept.

## What it does
- Uses **WebXR** via **A‑Frame** and **AR.js** (marker‑based AR) to overlay a 3D advertisement on a physical marker (the classic "hiro" marker).
- The ad is a rotating rectangular box textured with a random image, representing a product or banner.
- Runs entirely in the browser – no server, no paid services.

## How to run
1. Make sure you have a webcam (or an AR‑glass device that can expose a camera to the browser).
2. Open `index.html` in a modern browser (Chrome, Edge, or Firefox).
3. Point the camera at a Hiro marker (print it from https://github.com/AR-js-org/AR.js/blob/master/aframe/examples/marker-training/examples/hiro.png) and you’ll see the rotating ad appear on the marker.

No installation is required – just open the file locally.
