# builderbro money engine

Sequenced plan: **client work funds now, products build in the background.**

## Phase 1 — Client work (days 1–14)

Sell what is already provable: you ship complete systems solo.
See `services.md` for the menu, `outreach.md` for the prospecting kit.

- **Day 1:** service menu + landing page + outreach kit (this folder)
- **Day 2:** 50 targeted DMs/day, iterate on script
- **Day 3–5:** delivery starter-stack (reusable template repo) — target: every job ships in 1–2 days
- **Day 6–7:** Upwork niche profile + 10 proposals/day

**Weekly rhythm after that:**
- 4 days delivery, 1 day outreach, half day admin. Full-time = 40h.
- Pipeline rule: never let active work drop below 2 jobs. When it does, outreach is the *most important task* that day, not the last one.

## Phase 2 — Productize (weeks 2–4, background)

| Asset | Product | Monetization |
|---|---|---|
| `qrbtc-api` | Hosted behavioral trust/reputation API (live + DOI) | Freemium → usage tiers |
| `passionstate-nexus` | Agent governance / review gate (MCP surface) | License per-seat or per-review |

## Rules of the game

1. **First dollar beats perfect.** Ship the offer, take a small client, learn the delivery loop — then raise prices.
2. **Prices rise every 3 jobs.** $300 → $500 → $800. The work doesn't change; your confidence does.
3. **Never pitch the product.** Pitch the outcome ("your customers stop asking the same 20 questions at 2am").
4. **One thin line:** no fraud/carding/credential theft. Everything else is fair game.
